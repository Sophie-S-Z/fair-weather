# M4 playtest kit: the whole game and the sandbox

This kit is for the launch playtest (T11, ADR 0014 item 17). The playtest checks success criteria S1 to S4 (spec 3.5). It also checks every hero in every valley (ADR 0013 item 15).

- **S1:** Bet accuracy rises from chapter 2 to chapter 8, in aggregate.
- **S2:** At least 60% of the players who start Part 1 finish it. At least 40% finish Part 2.
- **S3:** Each tester explains at least three core ideas without help.
- **S4:** Each tester names at least four different feelings.

Do five sessions. Use the codes Tester A, Tester B, Tester C, Tester D, and Tester E. Do one session with one tester at a time. Write no real name.

This kit follows the form of the M1 kit (`docs/playtest/m1.md`). Read that kit first.

## 1. Before the sessions

1. Use a desktop or laptop computer with a keyboard and a mouse.
2. Install the project. Run `npm ci`.
3. Start the game. Run `npm run dev`. The production build does not run while placeholder content is in the game (ADR 0010).
4. Open the address that Vite shows. Do not add `?chapter`, `?fast`, or `?seed` to the address for Parts 1 and 2.
5. Open the browser tools. Delete the site data for the address. The game then starts with no save.
6. Close the browser tools.
7. Leave Sound at its default (off). Sound is not needed to play.
8. Go back to the title screen.
9. Print one copy of each results table (sections 5 to 9). Write the tester code on each copy.
10. Have a timer ready.

The development build shows `[PLACEHOLDER]` on some text. This is correct for M4. Tell the tester about it before they play.

## 2. Consent

Read this text to the tester. Use these words.

> Thank you for helping us. You will play a game for about two hours, with a break if you want one. Then I will ask you two questions.
>
> We test the game. We do not test you. There are no wrong answers.
>
> We do not record your name, your face, or your voice. We do not record the screen. I write notes on paper. The notes use a letter, for example Tester A, and not your name.
>
> You can stop at any time. You do not have to give a reason. If you stop, I destroy your notes if you ask me to.
>
> The game asks you to name your hero. The name stays on this computer. Do not use your own name.
>
> Do you agree to play and answer the questions?

Continue only if the tester says yes. If the tester says no, thank them and end the session.

Do not write the tester's name, age, email address, or other personal data on any page.

## 3. During play

Time plan. The times are a guess. Write the real times.

| Part | Time |
| --- | --- |
| Setup and consent | 5 minutes |
| Part 1, chapters 0 to 10 | 45 to 75 minutes |
| Part 2, the bridge and four valleys | 30 to 45 minutes |
| Sandbox | 15 minutes |
| Questions | 10 minutes |
| Total | 105 to 150 minutes |

A tester can stop after Part 1, take a break, and press Continue on the title screen. Write the break in the notes.

Do these steps:

1. Tell the tester: "Play until the game says The End. Think out loud if you want to."
2. Start the timer when the tester clicks Begin.
3. Do not explain the game. Do not answer questions about the game during play.
4. If the tester asks for help, say: "What do you think you can do?"
5. If the tester cannot move on for three minutes, tell them about the Skip chapter button. Write it in the notes with the chapter.
6. Write what the tester says, as near to their words as possible.
7. Write the chapter or valley next to each note.
8. Write down when the tester laughs, sighs, leans in, or looks away.
9. After each bet, write the answer and the result (section 5).
10. Stop the timer at "The End". Write the time.
11. Part 2 hero: see section 8. Tell the tester which hero to choose at the bridge. Tell them nothing else about the hero.
12. After "The End", go to the title screen. Tell the tester: "Open the Sandbox. Play with it for ten minutes. Then try one challenge." Do not explain the tools. Write what the tester does first, which panels the tester opens, and whether the tester shares a link or makes a postcard.

If the tester stops before "The End", write where the tester stopped (section 6) and ask: "What made you stop?" Write the answer. Then ask the questions in section 4 about what the tester played.

## 4. Questions

Ask the questions in this order. Ask each question one time. Do not suggest answers.

### Question 1 (S3)

Ask: **"Explain what happened in your own words."**

If the tester stops, ask: "Is there more?" Ask this one time only.

Write the answer. After the session, mark each core idea that the tester explains without help:

| Core idea (spec G1) | An example of a pass |
| --- | --- |
| Trust in repeated games | "The bench made the same friends meet again, so they were kind." |
| Noise and forgiveness | "A mistake in the fog did not end the friendship. They tried again." |
| Attention feedback loops | "When I looked at Pim and answered, Pim trusted the sky more." |
| Complex contagion and the majority illusion | "It seemed that everyone did it, but only the few I could see did it." |
| Local peaks | "They were happy with a small gain and did not look for a better one." |
| Voting rules | "The way they count the votes changed who won." |
| Sorting without malice | "Nobody was unkind, but the groups still split." |
| Costly signals | "A gift that costs something shows that they mean it." |
| Reputation | "The locals in the Hollow talked about my hero, and that changed how they met me." |

The tester can also explain that the game is a model with limits ("It is a simple model. Real trust is more complex."). Write it in the notes. It is not one of the nine ideas.

S3 passes for the tester when the tester explains three or more ideas.

### Question 2 (S4)

Ask: **"Name the feelings you had."**

If the tester stops, ask: "Did you have other feelings?" Ask this one time only.

Write each feeling with the tester's word. Do not change the word. If the tester gives the chapter, write it too. If not, ask: "When did you feel that?"

Count different feelings only. "Happy" and "glad" count as one feeling.

S4 passes for the tester when the tester names four or more different feelings.

The planned feeling for each chapter is in the `feeling` field of the files in `content/chapters/`.

## 10. After the sessions

1. Count the testers who pass S3 and S4. The target is five of five for each.
2. Do the S1 and S2 counts in sections 5 and 6.
3. Check that the hero grid in section 8 has no empty cell.
4. For each chapter and valley, compare the feelings named with the planned feeling. Write the differences.
5. Write the problems that more than one tester had.
6. Put the results in `docs/playtest/m4-results.md`. Use the codes Tester A to Tester E only.
7. Destroy the paper notes after you copy them.
