# Toybox Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the weather-year game with the toybox: one table, 12 different creatures, 8 props, 12 hidden discoveries, a sticker book, and lesson pages with small loops.

**Architecture:** Plain table state on the main thread, stepped at 30 Hz. Discoveries are `detect` functions that return a scene (a list of timed beats). A director plays one scene at a time. Pixi draws the table with the kept ink line renderer. Svelte draws the drawer, the book, the lesson pages, and an HTML button over each creature for pointer, keyboard, and screen readers. Lesson loops reuse the same table, director, and view on small fixed setups.

**Tech Stack:** TypeScript 6, Pixi 8, Svelte 5, Zod 4, Vite 8, Vitest 5, Playwright 1.64.

**Spec:** `docs/superpowers/specs/2026-11-17-toybox-design.md`

## Global Constraints

- Node 22.18 or later. No new runtime dependencies. Remove `inkjs`.
- Commit author `Sophie-S-Z`. No `Co-Authored-By`, no session links, no mention of AI in commits or the PR.
- All text for people (UI, stickers, docs) follows the owner's plain English rules. No em dashes.
- Creatures speak only in picture bubbles and chirps.
- One creature of each look. The 12 cast ids: `pim krit echo moss bell quill tove frog snail toadstool kite glassling`.
- Reduced motion: no boil, no wander, scenes jump to end poses. High contrast: ink width x1.5.
- `npm run lint`, `npm run typecheck`, `npm test`, and `npm run build` pass after each task.

## Review Focus

1. A drag that ends off the canvas or over the drawer: the creature drops at the nearest table point, never outside the floor.
2. A prop removed while its scene plays: the scene ends at once and frees its actors.
3. A creature held by the player when a scene would pick it: the scene does not start.
4. Window resize during play: positions stay in table units, and the view refits.
5. Blocked `localStorage`: found stickers last for the visit, no error.

### Task 2: Table state, step, and commands

**Interfaces produced:**
- `createTable(setup: TableSetup): Table` with `TableSetup = { seed; cast: [CastId, x, y][]; props?: [PropKind, x, y][]; ties?: [CastId, CastId][]; memory?: Record<string, Move>; wander?: boolean }`
- `step(t: Table, dt: number): void`
- Commands: `pickUp(t, id): boolean`, `moveHeld(t, x, y)`, `drop(t)`, `poke(t, id)`, `tie(t, a, b)`, `snip(t, a, b)`, `placeProp(t, kind): Prop`, `removeProp(t, kind)`, `moveProp(t, kind, x, y)`, `toggleProp(t, kind)`
- `critterAt`, `drainEvents(t): ToyEvent[]`

**Tests:** `tests/unit/toy/step.test.ts`: same seed and commands give the same positions; a held creature does not wander; `drop` clamps to the floor; dropping on a creature gives both a storm bubble; two creatures never overlap after 5 s; `pickUp` of a busy creature returns false.

- [ ] Write tests, see them fail, implement, see them pass, commit `feat(toy): add the table state, step, and player actions`.

### Task 3: Director and the twelve discoveries

**Interfaces:** `Discovery = { id: StickerId; detect(t: Table): Scene | null }`. `Scene = { id; actors: string[]; beats: Beat[]; length: number; unlock: StickerId[]; line: string }`. A `run` beat may return more beats, timed from now. The director checks discoveries only when no scene runs, skips any that would use a held creature, and keeps a 15 s cooldown per discovery.

**Tests:** `tests/unit/toy/discoveries.test.ts`: for each discovery, one setup that fires it and one near miss that does not. Cookie: Krit and Krit both grab and unlock `standoff`; Echo and Pim three rounds unlock `copycat`; a poke during the scene makes the poked creature grab. Puddle with one onlooker unlocks nothing. Removing a prop mid scene ends it.

- [ ] Write tests, see them fail, implement, see them pass, commit `feat(toy): add the director and the twelve discoveries`.
